# 淘寶、天貓與京東共用入口

共用入口；沿用現成瀏覽器 MCP，不另建登入或抓取服務。先搜尋當前可呼叫工具，工具清單可能跨輪改變；上輪沒有工具不代表這輪沒有。工具索引只能幫助發現，不能證明登入狀態。

## 可執行整合器

使用 [scripts/read-marketplace.js](scripts/read-marketplace.js)；這是兩套公開工具必要能力合併後的唯一實作，不需要啟動兩個上游服務。來源、取捨及驗收見 [接入資料](references/integrations.md)。

1. 用現有瀏覽器分頁與導覽工具打開商品或搜尋結果，不建立新瀏覽器。搜尋使用 `https://s.taobao.com/search?q=<經 URL 編碼的關鍵字>` 或 `https://search.jd.com/Search?keyword=<經 URL 編碼的關鍵字>`。
2. 讀取整合器檔案，把完整內容傳入 Playwright `browser_run_code_unsafe` 的 `code`。只有檔案在 MCP 允許根目錄內時才可傳 `filename`；跨 repo 被拒時改用 `code`，不複製第二份程式、不改允許根目錄。
3. 整合器只讀目前頁面，回傳登入狀態、商品與款式 ID、所選款式、價格、保固、文字參數、已載入評價、圖片類別與搜尋結果。未知不補 0；評價不自行用關鍵字判定好壞，不回傳評價者姓名。
4. 圖片每批預設 10、最多 20，總上限 500。續頁在 `code` 使用 `async (page) => { const read = <整合器完整函式>; return read(page, {offset: 10, limit: 10}); }`；依 `next_offset` 續讀，單次任務最多 5 批，仍有剩餘或 `images_truncated` 為真時要回報。輸出只包含圖片網址，不代表已讀圖；必要規格圖仍用既有看圖工具確認。
5. 不同款式價格直接重新讀取，不使用商品 ID 快取。登入、驗證或工具錯誤時停止當次讀取，保留原瀏覽器；需要人工掃碼才請使用者處理。

`price_status` 為 `visible_page_sku_unverified` 時，只證明讀到頁面價格，未證明所有必選款式已選完或價格已更新；必須比對 snapshot 與當前選項再引用為該款式價格。

登入與截圖、滾動及一般頁面操作沿用同一套 Playwright MCP；整合器不暴露任意點擊或另存 Cookie 的 API。

## 先找原本的登入

1. 使用者表示先前已登入時，優先找前文使用的瀏覽器工具與現有分頁。Playwright 使用 `browser_tabs` 的 list 動作取得當輪分頁，再選原分頁；只有空白分頁時，在同一瀏覽器開商品網址並讀取 snapshot。不得因空白分頁就認定登入遺失。
2. 以實際頁面判斷：能讀商品內容且顯示登入帳戶，表示這個瀏覽器目前已登入；僅有商品標題不能證明登入。登入表單、QR code、驗證提示、工具故障、商品下架、無庫存分開回報。
3. `curl`、requests、公開抓取服務與另一個瀏覽器不共享原登入。這些入口跳登入頁，不能推論原瀏覽器登出。工具缺額度也不能推論淘寶登入失效。不讀取、複製或輸出 Cookie、token、完整個資。
4. 原瀏覽器確實要求登入後，才展示該瀏覽器的 QR code 請使用者掃描；完成後讀回商品頁確認。過期才刷新一次，不自動反覆登入、不繞過驗證、不重建或清空使用者的瀏覽器資料。工具不可用時說明控制工具不可用，不能說帳戶已登出。

## 讀商品與比較

- 保留商品 `id` 與 `skuId`，讀回實際選中的款式、對應優惠價、幣別、保固；不要把最低價當成所選款式價格。不要按購買、加購、收藏或客服傳送。
- 必讀主圖與規格圖，不能只用頁面文字或圖片清單。若 snapshot 沒有 CPU、記憶體或 SSD，先讀圖片再說沒有資料。來源文字互相衝突時逐項指出，不能自行補齊。
- 區分賣家宣稱、第三方規格與實機測試；圖片顯示硬體規格不代表到貨實物已驗收。跨商品、款式或底座的相容結果不可直接沿用。
- 用商品原連結作來源；省略帳戶名稱與其他無關個資。缺資訊先完成能查的部分，不把可由頁面取得的資料交回使用者。

## 現成 MCP 整合

舊的兩套 MCP 不需要並行啟用；商品與搜尋讀取統一走上述整合器。若使用者原本登入只存在舊 MCP，先讀 [接入資料](references/integrations.md)，保留它作原瀏覽器入口，不強制搬移登入。工具切換後重新確認登入及所選款式。

2026-11-04 實測：直接 HTTP 取得登入跳轉，但原 Playwright 在空白分頁開啟商品後仍能讀已登入帳戶、商品、所選款式與價格。這是當次結果，不能當未來登入仍有效的證據。
