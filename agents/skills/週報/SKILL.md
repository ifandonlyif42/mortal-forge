# 週報

1. 在目前 repo 執行：`git log --all --since=<本週週一 00:00> --until=<明天 00:00> --author=<git config user.name> --no-merges --date=format:'%m-%d' --pretty='%ad %s'`。使用者指定別的期間或作者時照指定。
2. 依日期分組。每天只寫一行，格式：`**MM/DD（週幾）**：<做了什麼>`。
3. 每行以「功能或行為」為主題抽象，例如收銀台改善、庫存調整、預訂單改版、BUG 修復。不貼提交訊息原文、不列卡號與 AC 編號。
4. 有 BUG 修復時，寫清楚是哪個功能裡的 BUG，例如「修復退貨視窗規格顯示」，不可只寫「修 BUG」。
5. 同一天的多件事合成一句：主要改善在前，BUG 修復接在後。
6. 今天尚未結束時，該日標「（至目前）」。
7. 結尾一句說明資料來源是 git 提交，PR 合併與部署狀態未另查。

## 效果示範

沒有技能時（每天塞滿細節、帶卡號與 AC 編號）：
- 11/04（週三）：進貨單改善（#3602：整數成本、選品視窗、Excel 匯入、完成時併發處理）、預訂單驗收收尾（收據自動列印、會員累計消費、後台儀表板營收算法）、BUG 修復：退貨/取消視窗規格顯示、收銀員補印收據權限、排班員工下拉字色。

套用技能後（一天一句、只留功能與行為、BUG 標明所屬功能）：
- 11/04（週三）：進貨單改善與預訂單驗收收尾，並修復退貨視窗規格顯示、收據補印權限的 BUG。
